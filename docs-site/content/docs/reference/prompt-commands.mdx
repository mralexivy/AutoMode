---
title: "Prompt commands"
description: "Steer one Claude Code prompt with AutoMode am: commands. Force a model or effort, run or skip the workflow, continue after a pause, restore after /clear."
---

Start a prompt with `am:` to steer that one prompt. The next prompt routes as usual.

## Model and effort

| Command | Effect |
|---|---|
| `am:haiku`, `am:sonnet`, `am:opus` | Run this prompt on that model. |
| `am:low`, `am:medium`, `am:high`, `am:xhigh`, `am:max` | Run this prompt at that effort. |
| `am:reset` | Clear a pin and go back to automatic routing. |

```text title="Example"
am:opus review the auth middleware for timing attacks
```

## Workflow

| Command | Effect |
|---|---|
| `am:run <request>` | Run the plan, build, verify and review [workflow](/concepts/workflow). |
| `am:direct <request>` | Skip the workflow. |
| `am:explore <request>` | Map the repository with an isolated Haiku worker. |
| `am:new <request>` | Treat the prompt as a new task. |

## Guardian

| Command | Effect |
|---|---|
| `am:continue` | Resume after the guardian paused a turn. |
| `am:handoff` | After `/clear`, restore the saved task checkpoint. |

## Slash commands still count

Your own `/model` and `/effort` choices are pins. AutoMode reads them and keeps them until you change them, or until `am:reset`.
