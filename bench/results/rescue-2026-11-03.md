# Rescue ladder pilot, 2026-11-02 to 2026-11-03

This run is a pilot: 4 tasks, under 30. It counts toward no claim of a saving. All costs are list-price equivalents.

## What the runs found before any result counted

Each defect below made the rescue ladder a no-op in every arm. Each is fixed on this branch.

- **A real failure read as environment noise.** sqlglot's suite printed `FAILED (failures=3)` and then a version helper's `No module named 'setuptools_scm'`. The classifier filed the failure as environment, so the ladder never acted.
- **The agent could not run the tests.** 35 tasks install their dependencies into `.bench-deps` and grade with `PYTHONPATH=.bench-deps`. The agent ran without that path, and its checks failed on imports. The runner now gives the agent the grader's path.
- **A fixture that no arm could pass.** The pymarkdown-v2 reference failed its own `accept` against the host's Pygments 2.21 (`validate-fixture`: `valid: false`). Pygments 2.11.2 is now pinned.
- **Edits through Bash were invisible.** Sonnet edits with `sed -i` and Python heredocs. Each edit-and-test line became a new failure key. The ladder saw no edit and no repeat.
- **Narrowed checks.** The agent ran a full suite that failed, then subsets that passed, and stopped. A blocking gate now sends such a stop to the ladder as strong evidence.

## Mechanism, measured

- **The fork rung.** On the first request, 116,212 of 117,935 prompt tokens (98.5%) came from the warm cache, for $0.05. The rung's premise holds.
- **The Opus consult.** One consult cost $0.51 in measured subagent use.
- **The full chain on sqlglot.** In 2 runs, the chain ran effort, then the fork, then the consult, then the switch to Opus, at $3.46 and $3.91. Both failed. `opus-medium` also failed in the same window. The ladder cannot rescue what Opus fails.

## Decision

- **The rescue settings ship on**: `strongStep: effort-first`, `consult: priced`, `packet: fork-gated`, `forkRung: on`. On these tasks they cost the same per accepted run as the old defaults ($1.58 against $1.54). They are the only arm that passes the hard task. Each setting keeps its old value as an option.
- **The Sonnet executor with a blocking gate does not ship.** It is a third cheaper on the tasks it passes. On sqlglot it spends $2.85 a run on failures that the chain does not fix, so its cost per accepted run is the worst here.
