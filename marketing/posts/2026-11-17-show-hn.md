Hi HN. I built AutoMode, an open source (MIT) mod for Claude Code that picks the model and the reasoning effort for each prompt. Quick questions go to Haiku, edits to Sonnet, design and risky work to Opus. It runs on your own Claude login: no API key, no proxy, no server.

The part I'd most like feedback on is the benchmark, because the first one went badly.

Setup: tasks from pinned public repositories, each graded by hidden tests the agent never sees. Costs are list-price equivalents of every request, including AutoMode's own judge calls. The pass rule for each run was committed before its first row.

The first 30-task run showed AutoMode costing more than plain Opus. A rule sent every "hard, high-risk" task straight to Opus, and plain Sonnet high passed those same tasks far more cheaply. I changed it so hard work starts on Sonnet, and Opus only comes in on evidence: a failing check, a regression or a reviewer blocking the change. Then I reran.

Current numbers:

- 5 mixed sessions (question, task, question, harder task, all in one conversation): AutoMode $2.01, Sonnet high $2.14, effortless on Opus $3.87, plain Opus $4.14. All 20/20.
- 30 single coding tasks: AutoMode 29/30 at $0.275 per passed task, Opus 28/30 at $0.499, Sonnet high 30/30 at $0.240.

So, against Sonnet high on long single tasks, AutoMode is about 15% more expensive. The saving comes from sessions that start on Opus (the default) and mix questions with work. Each arm ran once, so treat this as a release signal, not a law.

Some engineering details that turned out to matter:

- Switching models mid-chat rewrites the whole conversation into the new model's prompt cache. AutoMode prices that rewrite before any switch and holds the current model when the saving would not pay it back.
- A risk floor in code (migrations, auth, data deletion and so on) cannot be overridden by the judge.
- The bar shows the estimated saving against the model you started on, including the cache rewrite you have to pay back first.

Benchmark write-up, rows and the reproduce command: https://mralexivy.github.io/AutoMode/benchmark/

I'm the author and I'm here all day. Happy to dig into methodology, the cache maths, or where it falls short.
