AutoMode vs Claude Code auto mode

By Alex Ivy, who makes AutoMode. Updated October 31, 2026.

They are two different things with similar names. Claude Code auto mode is a permission mode built by Anthropic. It decides whether an action can run without asking you. AutoMode is a free community plugin. It picks the model and the effort for each prompt.

Auto mode facts come from Anthropic's permission modes docs and announcement, read on 2026-10-31.

What is Claude Code auto mode?

Auto mode is a permission mode. Claude runs actions without routine permission prompts, and a separate classifier reviews each action first. The classifier blocks actions that go beyond your request. Anthropic's docs warn that it "reduces permission prompts but does not guarantee safety."

Start a session with claude --permission-mode auto, or press Shift+Tab to cycle modes. Auto mode does not choose your model. The /model setting does that.

What is AutoMode?

AutoMode is a free, open source Claude Code plugin. For each prompt, it picks a model and an effort. A quick fact can run on Haiku at Low. A security migration moves up to Opus, because code sets a risk floor that the judge cannot lower. Read how a route is decided.

Can I use both?

The two settings are separate. AutoMode does not change your permission mode, and auto mode does not pick your route. Auto mode does need a supported model, so check Anthropic's list if a session starts in Manual mode.

Install AutoMode

Paste these into Claude Code, one at a time, then run /reload-plugins.

/plugin marketplace add mralexivy/AutoMode
/plugin install automode@automode

It is free. It needs no key and no server, and it starts on its own.
