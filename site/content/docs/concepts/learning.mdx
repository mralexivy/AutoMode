**By default, AutoMode learns from your own sessions and corrects its own routes. You do nothing.** Four things run without being asked. Everything stays in files on your machine, and none of it holds prompt text.

| Part | Key | Default | What it does |
|---|---|---|---|
| Route memory | `learning` | `true` | A kind of task that needed rescue in this project starts on a stronger model next time. |
| Adaptive routing | `adaptive` | `true` | A small share of your tasks start on a cheaper model or lower effort. AutoMode adopts what holds up in your results and reverts what does not. |
| Learning pass | `reflect` | `auto` | When you have been away, it summarises what happened and sets the next experiments. |
| Cache keeper | `cacheKeeper` | `keepWarm: ask` | Measures your cache lifetime, asks before a cold send of a large chat, and offers to keep a long chat warm. |

Reading your past transcripts is the one thing that stays off until you agree (`/automode learned import`).

## Adaptive routing

On your own tasks, about one in seven starts a cheaper way: Haiku, or a lower effort on Sonnet. For each kind of task, AutoMode compares the cheaper arm with the held arm on cost and failures, and adopts the cheaper start only when the evidence is strong. It reverts when the cheaper arm fails more or costs more. A failure caused by the environment or a flaky test does not count against it. Safety floors, your `/model` and `/effort` pins, commands and critical-risk work are never touched.

## The learning pass

When you have been away 20 minutes, with at least three new tasks and six hours since the last pass, AutoMode finds the gaps locally and for free: where the money went, which cheaper starts won or lost, and which kinds of task are still untested. Then it asks Haiku once, about $0.001 (capped at $0.02 a pass and $0.20 a week), what to test next. The model sees numbers only. It can name only an experiment the engine already knows, and it only makes a probe start sooner. A score shows how many of its proposals your tasks confirmed, and how that compares with a simple rule (test the costliest untried tier first). Run `/automode learn` for a pass now and `/automode learned` to see what it found.

## Make it manual, or turn it off

Put a `config.json` in the plugin data directory:

```json
{ "reflect": "manual" }
```

| You want | Set |
|---|---|
| The learning pass only when you ask | `"reflect": "manual"` |
| No learning pass | `"reflect": "off"` |
| A pass that costs nothing | `"reflectModel": false` |
| No cheaper-start experiments | `"adaptive": false` |
| No route memory | `"learning": false` |
| No cache keeper prompts or pings | `"cacheKeeper": { "guard": false, "keepWarm": "off" }` |
| Everything off | `AUTOMODE_ROUTER=off` |

`/automode learned reset` erases what it learned.

## Route memory

AutoMode keeps a small memory per project. A kind of task that needed rescue in this project starts on a stronger model next time.

## How it decides

<Steps>
  <Step>
    ### Each task is filed

    After every turn, and after a correction, the task goes into a bucket: its tier and its need.
  </Step>
  <Step>
    ### The outcome is rated

    A task is **bad** when it moved up to Opus after an escalation, or when you corrected or retried it. It is **ok** when a check passed.
  </Step>
  <Step>
    ### A bucket moves up

    Once a bucket has 2 bad tasks and a 40% bad share in 30 days, the cheaper models are left out for that bucket.
  </Step>
</Steps>

## What it never does

- It never lowers a route. Learning only raises one.
- It never overrides a pin. Your `/model` keeps its model.
- It never stores prompt text. The file holds task ids, tier and model labels, outcomes and times.

## Where it lives

`~/.claude/plugins/data/automode/learned-<project hash>.json`. It keeps the last 400 tasks. Delete the file to forget a project.

## Turn it off

Set `"learning": false` in `config.json`, or run `/plugin configure automode@automode` and set **Route learning** to `off`.

`node bench/learn-replay.mts` replays your own decision records through the learning rules. It calls no model and costs nothing.
