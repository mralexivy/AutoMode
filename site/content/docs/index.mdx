**AutoMode is a model router for Claude Code.** It picks the right model and the right effort for every prompt. Quick questions stay cheap on Haiku. Everyday coding runs on Sonnet. Hard and risky work gets Opus, and risky changes always get an independent review.

It is a Claude Code **mod**: a plugin whose TypeScript registers event handlers. It needs no API key and no server. It runs on the Claude login you already have, and your data stays on your machine.

```text title="Paste into Claude Code, one line at a time"
/plugin marketplace add mralexivy/AutoMode
/plugin install automode@automode
/reload-plugins
```

## What changes when you install it

|  | Without AutoMode | With AutoMode |
|---|---|---|
| **Model** | One model for every prompt | Haiku for a quick fact, Sonnet for an edit, Opus for design and risk |
| **Effort** | You set it, and you forget to change it | A judge sets it for each prompt, in about a second |
| **Risky changes** | The same checks as a typo fix | Security, migrations and payments always get an independent review |
| **Big jobs** | One long chat that does everything | A plan, build, verify and review workflow with six small agents |
| **Prompt cache** | A cold cache is a surprise bill | A countdown on the bar shows when the cache goes cold |

<Callout title="Not Claude Code's auto permission mode">
  AutoMode is a community project. It is not the built-in auto permission mode, and Anthropic does not make it. [See the difference](/docs/guides/auto-mode-vs-automode).
</Callout>
