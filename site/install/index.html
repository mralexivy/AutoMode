How to install AutoMode in Claude Code

By Alex Ivy, who makes AutoMode. Updated November 5, 2026.

Installing AutoMode takes two commands and one reload. In Claude Code, run /plugin marketplace add mralexivy/AutoMode, then /plugin install automode@automode, then /reload-plugins. AutoMode then starts with every session. It needs Claude Code 2.1.287 or later, no API key and no server.

Step by step

  1. Add the marketplace: /plugin marketplace add mralexivy/AutoMode
  2. Install the plugin: /plugin install automode@automode
  3. Reload: /reload-plugins, or restart Claude Code.
  4. Check it runs: /automode setup prints a live checklist.

Install from a terminal

claude plugin marketplace add mralexivy/AutoMode; claude plugin install automode@automode

Or ask Claude Code to do it: "Install the AutoMode plugin for me: run claude plugin marketplace add mralexivy/AutoMode and then claude plugin install automode@automode. When both succeed, tell me to run /reload-plugins."

What do I need?

  • Claude Code 2.1.287 or later in the terminal. The Desktop app needs 2.1.286 or later, and the VS Code extension 2.1.299 or later.
  • Your normal Claude login. There is no key to add.

How do I know it works?

Run /plugin. A line under the tabs reads 1 mod active · automode. In the terminal, a bar above the prompt shows the model and effort of each prompt. In VS Code, run /automode for the same facts. If the mod does not load, Claude Code runs as usual and nothing breaks.

Troubleshooting

SymptomCheck
Nothing changes after installRun /reload-plugins, then /plugin, and look for 1 mod active · automode
The mod is not listedCheck that claude --version is 2.1.287 or later
The bar is missing in VS CodeExpected. Use /automode
A hook seems skippedStart with claude --debug and search the log for automode
Filing a bugRun /automode debug and paste the result into an issue

How do I turn it off or remove it?

  • One session: /automode off. Start it again with /automode on.
  • Everywhere: disable it in the Installed tab of /plugin.
  • Remove it: claude plugin uninstall automode@automode. Its state lives in ~/.claude/plugins/data/automode/.
