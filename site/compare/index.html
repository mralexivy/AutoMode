Claude Code model routers compared

By Alex Ivy, who makes AutoMode. Updated November 5, 2026.

A Claude Code model router picks a model for each prompt, so you stop switching by hand. The main options differ in how they run, what they route and what they can prove. We make AutoMode, so read this as a maker's view. Each row comes from the project's own README.

These projects change quickly. Feature rows come from the READMEs, read on 2026-10-30 and 2026-10-31. The cost row comes from our own benchmark run on 2026-11-04. If a cell is wrong, open an issue.

Where the others are ahead

  • effortless is simpler. It does one job.
  • jev-router also runs on Codex. AutoMode runs only in Claude Code.
  • claude-router lets you choose the classifier, including a local Ollama model. AutoMode's judge always runs on Haiku, through your Claude login.

AutoMode is not independent of these projects. Its effort rules and bar techniques are ported from effortless. Its classifier contract and switch payback are adapted from claude-router and jev-router.

Other tools with similar names

  • ClaudeRouter classifies each prompt and delegates to Haiku, Sonnet or Opus. It installs from npm, and its README lists a Pro or Max plan as a requirement for delegation.
  • claude-model-router tracks token use and routes sub-tasks to subagents, rather than the main prompt. Its 35 to 50% figure is its own claim.
  • Claude Code Router does a different job. It is a local app that connects coding agents to the providers you choose, then routes and fails over between them. Pick it to reach other providers.

Which one should you pick?

  • You want effort routing and nothing more: effortless.
  • You also use Codex: jev-router.
  • You want to run the classifier locally: claude-router.
  • You want to reach non-Anthropic models: Claude Code Router.
  • You want model and effort routing, risk floors and a review workflow with no key: AutoMode.

Does a router save money?

It can, and it can also cost more. A model switch in a warm chat rewrites the prompt cache, and a moved conversation can cost more than it saves. AutoMode's measured result: 51% less than Opus in mixed sessions and 45% less on 30 coding tasks, at the same pass rate. On long single coding tasks it costs about what Sonnet high costs. The rows and the decision rules are public, so you can repeat the run.

Install AutoMode

Paste these into Claude Code, one at a time, then run /reload-plugins.

/plugin marketplace add mralexivy/AutoMode
/plugin install automode@automode

It is free. It needs no key and no server, and it starts on its own.
