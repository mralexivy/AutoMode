Claude Code cost calculator

By Alex Ivy, who makes AutoMode. Updated November 5, 2026.

At 50 questions and 20 coding tasks a week, Claude Code on Opus costs about $42.35 a month at list price, and AutoMode about $18.45, 56% less. The estimate multiplies your weekly mix by the cost of each step in our benchmark: a question cost $0.050 on Opus and $0.008 on AutoMode, and a coding task $0.364 on Opus and $0.193 on AutoMode. Change the numbers below to match how you work.

A month here is 4.33 weeks. On a Pro or Max plan you pay a flat price, so read the difference as the share of your usage limits you would save.

Where do the numbers come from?

Each arm ran the same five mixed sessions on real repositories: a question, a task, another question, then a harder task, in one conversation. Hidden tests graded every task, and every arm passed all 20 steps. Costs are list-price equivalents of every paid request, judges and subagents included.

When is the estimate wrong?

  • Your tasks are longer or shorter than the benchmark's. Cost grows with context, so long sessions cost more on every arm.
  • You only run coding tasks on Sonnet high. Then AutoMode costs about the same, a little more for its judges and checks.
  • One repetition per arm. The benchmark is a release signal, not a law. Read its method and limits.

Install AutoMode

Paste these into Claude Code, one at a time, then run /reload-plugins.

/plugin marketplace add mralexivy/AutoMode
/plugin install automode@automode

It is free. It needs no key and no server, and it starts on its own. Read the install guide.
