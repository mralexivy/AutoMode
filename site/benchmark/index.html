Claude Code router benchmark

By Alex Ivy, who makes AutoMode. Updated November 5, 2026.

In five mixed Claude Code sessions on real repositories, AutoMode cost $2.01 and plain Claude Code on Opus cost $4.14. That is 51% less, and both passed all 20 steps. On 30 single coding tasks, AutoMode passed 29 at $0.275 per passed task, and plain Opus passed 28 at $0.499. Hidden tests the agent never saw graded every task. Every cost is a list-price equivalent of every paid request, judges and subagents included.

Mixed sessions: questions and coding in one conversation

Each session runs as one continuing conversation, the way people use Claude Code: a question, a task, another question, then a harder task. Every task is graded by its own hidden tests, and every answer by the facts it must name.

The cost ratio against Opus is 0.551, with a 90% interval of 0.511 to 0.591. That clears the ship rule fixed before the run: no task lost, and a ratio of 0.85 or less. The one task AutoMode missed, sqlglot, plain Opus failed too. The Sonnet high rows come from an earlier run on the same tasks and tests.

Where AutoMode does not win

  • Long single coding tasks with no questions. AutoMode runs them on Sonnet, so it costs about 15% more than plain Sonnet high, for its judges and checks. If you only run long coding tasks on Sonnet high already, AutoMode saves you little.
  • Haiku on hard work. A Haiku-first mode cost 44% less than Sonnet high on 14 tasks, $1.74 against $3.09, but it failed one task that Sonnet high passed. So it ships off.

How the numbers were made

  • Same tasks, hidden tests. Each arm ran the same tasks on the same pinned repository commits. Tests the agent never saw decide pass or fail.
  • Rules fixed first. Every decision rule and budget was committed before the first row of its run.
  • Sessions start on Opus, as most people run Claude Code. effortless ran at its pinned commit, as its author ships it.
  • One repetition per arm. Treat this as a release signal, not a general law.
