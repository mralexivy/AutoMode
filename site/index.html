Read it before you run it

A mod runs with your permissions, and AutoMode sees every prompt and tool call, because that is how routing works. So all of it is open.

What leaves your machine

No telemetry and no network code of its own. Judge and compaction calls go through Claude Code, on your own login.

What it stores

Local files in its own data folder, with retention limits. Read PRIVACY.md.

What it can do

Run claude plugin validate on a clone to list every hook and API call. See the table.
