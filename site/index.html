Questions people ask

What is AutoMode?

AutoMode is a free, open source plugin for Claude Code. It picks the model and the effort for each prompt, sets a quality floor for risky work, and runs a plan, build, verify and review workflow for big jobs.

Is AutoMode the same as Claude Code auto mode?

No. Claude Code auto mode is a built-in permission mode from Anthropic. It decides whether an action runs without asking you. AutoMode is a community plugin that picks the model and effort. Read the full difference.

How do I stop switching Claude Code models by hand?

Install a model router such as AutoMode. It chooses Haiku, Sonnet or Opus for each prompt, so you do not touch the model picker. You can still override any prompt with am:opus or am:haiku. See how a route is decided.

Does AutoMode need an API key?

No. AutoMode runs on the Claude login you already have. There is no key, no server and no account to make.

Does AutoMode save money?

We do not know yet. AutoMode has no published cost result, so we quote no saving. A model switch in a warm chat can also cost more, so AutoMode checks each switch first. Read about the prompt cache.

Does AutoMode send my prompts anywhere?

AutoMode has no telemetry and no network code of its own. Judge and compaction calls go through Claude Code, on your own login. It stores local files in its own data folder.

Does AutoMode work in VS Code?

Yes. Routing runs in the VS Code extension. Claude Code does not draw the bar there, so use the /automode command for the same facts.

How does AutoMode compare with other routers?

AutoMode adds risk floors and a review workflow, and it needs no key. Others are ahead in places: effortless has a published cost result, and jev-router also runs on Codex. Compare Claude Code routers.
